# Kai. Rajaram Sawala Dudhade Foundation Website

Static multilingual website package for GitHub Pages, Vercel, Netlify, or any normal hosting.

## What is included

- English, Marathi, and Hindi language selector
- Foundation identity and address sections
- Services, membership, donation readiness, privacy, refund, and terms content
- Membership certificate preview
- Mobile app / Razorpay readiness checklist

## Client handoff notes

You can create this website under your GitHub account now. Later, either transfer the repository to the client GitHub account or keep the repository under your account and add the client as an owner/collaborator. For a public foundation website, GitHub Pages, Vercel, Netlify, or Cloudflare Pages will all work.

Before Razorpay integration, replace placeholder contact fields with:

- Client domain email
- Verified phone number
- Official registration details
- PAN / bank account details in Razorpay dashboard only, not in public code
