# Kai. Rajaram Sawala Dudhade Foundation Website

Production static website for Kai. Rajaram Sawala Dudhade Foundation.

## Included

- English, Marathi, and Hindi language selector
- Foundation identity, founder/president, and address section
- Service categories for medical help, blood donation, education support, financial help, donation programs, volunteer service, awareness, and community welfare
- Membership process section with certificate preview
- Dedicated mobile app routing section for the approved Android app link
- Official social channel disclosures for YouTube, Facebook, and Instagram
- Payment, privacy, refund/correction, and user responsibility disclosures
- Operator/request workflow explanation for client and Razorpay review context
