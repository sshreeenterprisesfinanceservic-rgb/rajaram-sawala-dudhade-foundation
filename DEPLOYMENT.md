## Custom Domain Steps

1. Buy or confirm the client domain.
2. Add the domain in GitHub repository Settings > Pages > Custom domain.
3. Add the required DNS records at the domain provider.
4. Wait for DNS propagation.
5. Confirm HTTPS enforcement in GitHub Pages.
6. Use the final domain in Razorpay/client documentation.
